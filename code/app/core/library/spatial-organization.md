# Spatial organization

Divide the board into four 4×4 quadrants:

- Bottom-left: a1–d4
- Bottom-right: e1–h4
- Top-left: a5–d8
- Top-right: e5–h8

Locate the quadrant first, then the individual square.

Gradually develop direct recognition without consciously identifying quadrants.

Quadrants are useful potential anchors, not a proven superior technique.

This is my preferred approach.
