# Colour relationships

Adjacent squares alternate colours horizontally and vertically.

Squares along the same diagonal share one colour.

A bishop always remains on its original square colour.

Example: The bishop on c1 occupies dark squares only.

It cannot attack e4 because e4 is light.

A knight changes square colour after every move.

So a knight needs an odd number of moves between squares of different colours, and an even number between squares of the same colour.

These relationships help verify moves during blindfold chess.

Proven: FIDE Laws of Chess, Articles 2.1, 2.4, 3.2 and 3.6; Chess Programming Wiki, Knight-Distance. Their use for verifying moves is my preferred approach.
