# Writing a move

Before writing a move, ask four questions.

Does it take a piece? Write x before the square.

Is it a pawn's capture? Start with the file it leaves.

Can another piece of that kind reach that square? Name its file. If they share the file, its rank.

Does it give check, or mate? Add + or #.

A piece that cannot legally move there, such as one pinned to its king, does not count as that other piece.

Castling is O-O or O-O-O. A promotion adds =Q after the square.

Gradually ask them without thinking.

Proven: the PGN standard, section 8.2.3, writes x, + and # on every move. FIDE makes them optional. Writing them every time is my preferred approach.
