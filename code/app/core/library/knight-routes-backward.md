# Knight routes, planned backward

Plan a knight route from its target, not its start.

Find the squares one knight move from the target.

Can the knight reach one of them? That is the route.

If not, step back once more from those squares.

Example: g1 to e5. f3 reaches e5, and g1 reaches f3.

Check every landing square. A knight jumps pieces, never lands on its own.

It is one method, not the only one. Gradually see routes directly.

This is my preferred approach. Unverified: no reference teaches or tests it.
