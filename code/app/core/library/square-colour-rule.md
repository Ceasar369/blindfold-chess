# Square colour rule

Every chessboard square has a permanent colour.

Number files from a=1 through h=8.

Add the file number and rank.

- Even sum: dark square.
- Odd sum: light square.

Example: f5 → 6 + 5 = 11 → light.

Square colours never change with board orientation.

Proven: FIDE Laws of Chess, Article 2.1.
