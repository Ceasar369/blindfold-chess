# Holding an opening

Hold a known opening as the starting position plus the pieces that moved.

Italian Game: the starting position, with White's pawn on e4, knight on f3 and bishop on c4, and Black's pawn on e5 and knight on c6.

Rebuild it from its name alone: start from the starting position, and move only those pieces.

Gradually see the whole position at once.

This is my preferred approach, from templates in expert memory (Gobet and Simon 1996). Unverified: no study tests it for players near 1000.
