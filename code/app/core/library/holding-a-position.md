# Holding a position

Hold a position as a few groups, never as loose pieces.

Place the kings first. They anchor everything else.

Then the pawns: they move least, and shape the rest.

Then the other pieces.

Check what I hold: name every piece and its square.

Gradually see the groups at once.

This is my preferred approach, from one drill: kings, then pawns, then the rest, held in groups. Two players put pawns first. Unverified: no study tests it.
