# Real positions

Practise position memory on positions from real games.

Practice raised recall of game positions a lot. Recall of random positions barely rose.

Strong players beat weak ones mainly on real positions. On random positions the gap is small.

Proven: Gobet and Jackson 2001, two novices, recall of game positions rose and random positions barely; Gobet and Simon 1996, the skill gap is far smaller on random positions; Astudillo and Sandoval 2026, 51 novices rebuilt real positions better than random ones. Practising on real positions is my preferred approach.
